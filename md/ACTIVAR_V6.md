# Activar la V6

1. Firebase → Bingo de Eli → Firestore → Reglas. Sustituir todo el contenido por el de FIREBASE_REGLAS_DEFINITIVAS.txt de esta misma carpeta y pulsar Publicar. No cambiar Authentication ni borrar usuarios.
2. GitHub: subir bingo.js, bingo.css, sw.js y arbol-navidad.png desde Bingo. Si V5 no estaba publicada, subir también index.html, manifest.webmanifest, icon-bombo.png y bombo-giro.mp4.
3. Recargar la web y comprobar V6. Entrar con el correo y contraseña habituales de Elisabeth.
4. Configuración → Administración general: aprobar solicitudes de otras familias. Ellas crean su partida y comparten su propia invitación. Los invitados no necesitan cuenta.

Los botones de borrar retiran accesos o partidas de forma recuperable. No borran cuentas de Authentication ni eliminan documentos definitivamente. La cuenta principal está protegida.
